# Quality History

This folder stores historical quality snapshots generated by `summarize-checkengine-results.ps1`.

## Files

- `checkengine-quality-history.csv` — append-only trend file.

## Columns

- `timestamp_utc`
- `total`
- `passed`
- `failed`
- `skipped`
- `duration_seconds`
- `line_coverage_percent`
- `branch_coverage_percent`

## Usage

Run local quality gate:

`powershell -ExecutionPolicy Bypass -File .\CheckEngine\scripts\run-checkengine-quality.ps1`

The summary script appends a new row automatically after each run.
